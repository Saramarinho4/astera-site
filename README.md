# Ástera ✦

> Pequenas soluções para uma rotina mais leve, organizada e bonita.

A **Ástera ✦** é uma marca de produtos digitais criada para transformar organização e planejamento em experiências mais simples, funcionais e agradáveis.

Cada detalhe da marca foi pensado para unir **praticidade e delicadeza**, criando produtos que não apenas ajudam na rotina, mas também tornam o processo mais leve.

## ✦ A marca

A Ástera acredita que organização não precisa ser complicada.

Por isso, seus produtos são desenvolvidos com uma proposta simples: **facilitar o dia a dia sem abrir mão da estética**.

Entre planilhas, planners e ferramentas digitais, a marca busca criar soluções que sejam úteis de verdade, fáceis de usar e bonitas de ter por perto.

## ✦ Produtos

A loja apresenta produtos digitais pensados para diferentes momentos da rotina:

**Planilha Financeira Pessoal**  
Uma forma mais simples de acompanhar, organizar e visualizar a vida financeira.

**Controle de Vendas**  
Uma ferramenta prática para acompanhar vendas e manter as informações importantes organizadas.

**Planner 2027**  
Um espaço para planejar dias, metas e momentos com mais intenção.

**Ástera Creator ✦**  
Uma proposta voltada para criadores que desejam transformar suas ideias em conteúdo e presença digital.

## ✦ Uma identidade com intenção

A identidade visual da Ástera foi construída para transmitir uma sensação de leveza, cuidado e sofisticação.

O lilás aparece como elemento principal, acompanhado por espaços claros, formas delicadas e o símbolo **✦**, que se tornou parte da personalidade da marca.

A estética é minimalista, mas não fria.

É delicada, mas não excessivamente romântica.

É simples, mas pensada em cada detalhe.

## ✦ O site

O site oficial foi desenvolvido para ser uma extensão da própria marca: limpo, intuitivo e visualmente delicado.

A experiência foi pensada para que cada visitante consiga:

- conhecer a Ástera
- descobrir os produtos
- entender o que cada produto oferece
- acessar os respectivos checkouts
- encontrar os canais oficiais da marca
- navegar de forma confortável em diferentes dispositivos

## ✦ Tecnologia

O site foi desenvolvido com tecnologias web fundamentais:

- HTML5
- CSS3
- JavaScript
- SVG

A estrutura é leve, responsiva e preparada para hospedagem estática através do GitHub Pages.
